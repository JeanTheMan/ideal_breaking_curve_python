# Ideal Breaking Curve

Hello, this is my submission for the QMFS software team

## Programming Language

For this project, I have decidied to use python. I believe that python is a good fit for the project because it has the MatPlotLib module which is a well-documented and reliable graph plttoting module that is simple and easy to use. Since performance and memory efficiency are not requirements in the project, I belive that python was the easiest language to create a simple script for it. I chose to not use any OOP or function declarations as the script only needs to perform the same calculation and is not designed to be built upon after.

## How to run

1. Make sure python 3 is installed in your system (tested on 3.14)
2. Ensure that matplotlib is installed to the latest version or install it using `pip install matplotlib` (optionally create a venv)
3. run by opening a terminal in the same directory and running `python3 main.py`

## Other Assumptions and Decisions

After finding very little information on the matter online and the video not providing any formula context, I made the assumption that the acceleration of the car in the formula meant the deceleration caused by friction, which I modeled by gravity * frictional coefficient for each coefficent

All other calculations where derived fully from the provided formulae and constants

I decided to plot the graph for coefficients going up in 0.1 like the graph in the video

The graph was made to represent the one in the video as close as possible.
